# InsureGuard — Insurance Compliance QA Demo

A prototype demo for insurance marketing compliance quality assurance. Simulates automated scanning of marketing assets against IRDAI/brand/legal rules with a maker-checker approval workflow.

## Demo Features

- **Dashboard** — Real-time compliance stats, recent assets, top violations
- **Checklist Builder** — Toggle compliance rules by category (Color, Text, Legal/IRDAI, Image, Brand)
- **Upload & Scan** — Simulated scan with progress animation and pass/fail results
- **Scan Report** — Detailed violation breakdown with Figma integration simulation
- **Checker Queue** — Maker-checker approval workflow (approve/reject with comments)
- **Audit Log** — Filterable event history with export simulation

## How to Run

Simply open `insurance_compliance_qa_demo.html` in any modern browser. No server or build step required.

```
open insurance_compliance_qa_demo.html
```

## Tech Stack

- Pure HTML/CSS/JS — zero dependencies
- Tabler Icons (CDN) — icon library
- CSS custom properties — theming
